# 🌐 Meu Portal de Entretenimento Digital

Este é um projeto de portal de entretenimento moderno e responsivo, desenvolvido como atividade acadêmica. O site apresenta três categorias principais de conteúdo organizadas em formato de "cards" elegantes e centralizados.

## 🚀 Tecnologias Utilizadas
* **HTML5:** Estrutura e marcação do conteúdo.
* **CSS3:** Estilização avançada com Flexbox para o design compacto (Dark Mode).
* **JavaScript:** Interatividade rápida integrada para navegação resiliente.

## 📁 Estrutura do Projeto
* `index.html` - Página principal do portal.
* `filmes.html` - Página da categoria de Filmes e Séries.
* `games.html` - Página da categoria de Games e Tecnologia.
* `musicaportal.html` - Página da categoria de Música e Podcasts.
* Imagens locais para carregamento estável offline.

## 🛠️ Como Executar o Projeto
1. Faça o clone ou download deste repositório.
2. Abra o arquivo `index.html` em qualquer navegador (Chrome, Edge, Firefox).
